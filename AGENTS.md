# AGENTS.md

## Архитектура

- M1STRELL — клиентское портфолио на JavaScript, JSX и CSS. Стек портфолио — React 19, React Router 7, Vite 8 и ESLint 10. `vercel.json` направляет запросы к маршрутам на `index.html`.
- Точка входа `src/main.jsx` подключает `BrowserRouter`, контекст языка и общие стили. Действующие маршруты `/`, `/about`, `/projects` и экран 404 объявлены в `src/App.jsx`. Перед использованием модулей из `src/pages/` и `src/components/` проверь их связь с действующими маршрутами.
- Данные проектов, профиля и контактов находятся в `src/data/projects.js`, изображения — в `src/assets/`, статические ресурсы — в `public/`. Стили портфолио находятся в `src/portfolio-v2.css`, общие стили и токены — в `src/styles/`.
- Переиспользуй действующие компоненты, данные и стили, когда это сохраняет нужное поведение. Не добавляй ненужные зависимости и не переписывай работающую архитектуру без конкретного обоснования.

## Разработка и проверка

- Сначала прочитай существующую реализацию, проследи путь от маршрута до компонентов и данных. При исправлении ошибки по возможности воспроизведи её и установи первопричину.
- Сохраняй существующие пользовательские сценарии за пределами согласованного изменения. Избегай дублирования компонентов. Для интерфейса учитывай узкие экраны, семантику, контраст, клавиатурную навигацию, видимый фокус и `prefers-reduced-motion`.
- После изменений приложения запускай `npm run build` и `npm run lint`. Используй `npm run dev` для локального запуска. Проверь затронутые пользовательские сценарии, а при изменении интерфейса — мобильную и десктопную ширину. Сообщай о фактических результатах и ограничениях проверок.

## Дизайн

- Сохраняй эмблему M1STRELL, тёмную палитру, звёздный мотив и сдержанную композицию. Для подходящих задач UI/UX используй `design-intelligence`, если навык доступен.
- Не копируй чужие сайты. Избегай шаблонной AI-эстетики. Подбирай типографику, композицию и движение под содержание и задачи посетителя.
- Для существенных визуальных изменений сначала предложи концепцию. Реализуй выбранный вариант после утверждения владельцем. Когда появится `DESIGN.md`, используй его как основной источник визуальных правил проекта.

## Контент портфолио

- IQNIX PTM и Geralt’s World намеренно отключены от публичного хостинга. Сохраняй оба проекта в портфолио и не запускай их на Railway.
- Показывай ссылки на демоверсии только при подтверждённой доступности. Для отключённых демо используй кейсы, рабочие скриншоты, описания и ссылки на GitHub.
- Подтверждай личный вклад владельца, технологии и технические решения по исходникам и сведениям от владельца. Не придумывай опыт, результаты, достижения или технологии.

## Безопасность изменений

- Перед работой проверь `git status` и активную ветку командой `git branch --show-current`. Береги существующие правки и не изменяй ветку `portfolio-restored`.
- Выполняй push, деплой и изменения хостинга только по явному разрешению владельца.
- Перед удалением файлов проанализируй их использование в коде, маршрутах и сборке.
